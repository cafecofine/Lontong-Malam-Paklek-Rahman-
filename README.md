# Lontong-Malam-Paklek-Rahman-
Lontong Malam Pak Lek Rahman adalah kuliner malam andalan di Medan. Hidangan lontong sayurnya disiram kuah gulai gurih yang melimpah khas masakan rumah. Pilihan lauknya sangat beragam, mulai dari ayam rendang, ayam semur, ayam pop, hingga ikan sambel dan tempe bacem. Selain lontong, tersedia juga nasi gurih kuning yang menggugah selera.
